# Repository Instructions

- Use npm for all package management.
- Run `npm run check` before finalizing frontend changes when practical.
- Keep UI mobile-first, senior-friendly, high contrast, and accessible.
- Prefer small focused changes over broad refactors.
- Do not commit secrets or local `.env` files.
- Keep environment variable documentation in `.env.example`.
- Keep shared components semantic and keyboard accessible.
- Avoid unnecessary UI libraries and premature design-system complexity.
- Keep future Supabase work behind `src/lib/supabase.ts` or feature-level helpers.
